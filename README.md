# MuzLab — Telegram-бот для музыки

Телеграм-бот для поиска, скачивания и организации музыки в плейлисты.

## Бот может

1. Скачивать песни
2. Создавать плейлисты
3. Добавлять новые песни или песни из истории пользователя в плейлисты
4. Показывать историю прослушивания

## Технологии

- [aiogram](https://docs.aiogram.dev/) — асинхронный фреймворк для Telegram-ботов
- [aiosqlite](https://github.com/omnilib/aiosqlite) — асинхронная работа с SQLite, прост в использовании
- [aiohttp](https://docs.aiohttp.org/) — асинхронные HTTP-запросы для скачивания файлов
- [parse_hitmos](https://github.com/JoyHubN/pars_hitmos) — парсер для поиска треков

Скачивание песни может занять время. Но бот работает асинхронно, поэтому можно делать несколько запросов одновременно.

## Важно

Создайте файл `.env` в корне проекта и добавьте туда токен бота:
   ```
   BOT_TOKEN=abc
   ```
   Токен можно получить у [@BotFather](https://t.me/BotFather) в Telegram.

## Запуск

```bash
python music_bot.py
```

## Структура проекта

- `music_bot.py` — основная логика бота, хендлеры сообщений и колбэков
- `songs_db.py` — работа с базой данных
- `states.py` — состояния FSM для многошаговых сценариев (создание плейлиста, добавление песни и т.д.)
